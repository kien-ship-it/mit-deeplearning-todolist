# MIT 6.S191 Deep Learning - Accelerated Study Plan To-Do List

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

This repository contains a simple, interactive webpage designed to help students follow an **accelerated 5-week study plan** for the **MIT 6.S191: Introduction to Deep Learning** course.

It provides a structured weekly to-do list based on the course lectures and labs, with integrated links to the official online course materials and persistent state saving using your browser's `localStorage`.

**Note:** This is an *unofficial* helper tool created based on the publicly available course content from [introtodeeplearning.com](http://introtodeeplearning.com/).

## ✨ Features

*   **Structured 5-Week Plan:** Follows the accelerated timeline discussed.
*   **Persistent State:** Your checked items and selected start date are saved locally in your browser, so your progress isn't lost when you close the tab.
*   **Start Date Selection:** Choose your starting date, and weekly deadlines will be calculated automatically.
*   **Deadline Calculation:** Each week shows a suggested completion date based on your chosen start date.
*   **Direct Links:** Includes links to official MIT 6.S191 resources (videos, slides, code repositories, papers) directly within the to-do items for easy access. (Requires internet connection).

## 🚀 Getting Started / How to Use

You can use this tool directly in your web browser without any installation.

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/kien-ship-it/mit-deeplearning-todolist.git
    ```

2.  **Navigate to the Folder:**
    ```bash
    cd mit-deeplearning-todolist
    ```

3.  **Open the Webpage:**
    *   Simply double-click the `index.html` file, or right-click and choose "Open with" your preferred web browser (Chrome, Firefox, Edge, Safari, etc.).

4.  **Using the Tool:**
    *   Select your desired **Start Date** using the date picker at the top. Deadlines for each week will update automatically.
    *   Check the boxes next to tasks as you complete them. Your progress will be saved automatically in your browser.

## 🛠️ Technology Stack

*   **HTML5:** Structure of the webpage.
*   **CSS3:** Basic styling for readability.
*   **JavaScript (Vanilla):** Handles interactivity, deadline calculations, and saving/loading state.
*   **Browser `localStorage`:** Used for persisting the to-do list state and start date across sessions.
